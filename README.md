# GM Codex

Modulo per Foundry VTT v13 pensato come manuale del GM semplice e lineare.

Contenuti principali:
- città e panoramiche;
- fazioni;
- PNG;
- missioni;
- luoghi e incontri fuori città;
- ricerca globale;
- condivisione dei Journal con i giocatori;
- contenuti salvati come JournalEntry nativi di Foundry.

La pubblicazione delle release installabili è automatizzata tramite `.github/workflows/release.yml`.
